# Clínicas Inteligentes
Protótipo organizado com HTML, CSS e JavaScript separados.

## Estrutura
- `index.html`: Arquivo principal da interface.
- `css/style.css`: Estilização visual (cores, layout, tipografia).
- `js/script.js`: Lógica do aplicativo, dados fictícios e controle de estado.
- `manifest.webmanifest`: Configuração para PWA (Progressive Web App).
